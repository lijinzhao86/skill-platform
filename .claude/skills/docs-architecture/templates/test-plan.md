| 标注 | 含义 |
|---|---|
| **已复现** | 实际跑出来过 |
| **部分复现** | 只在特定条件下触发 |
| **未验证** | 有人提出，但没独立复现 |
| **已修复** | 已被后续改动解决（注明日期与改动） |
