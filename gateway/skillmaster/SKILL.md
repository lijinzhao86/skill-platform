# 我的 skill 库

服务地址：`https://<host>`

## 使用协议（按顺序，不要跳步）

1. 检索：`skillmaster search "<关键词>"`
   → 只返回名称与描述。**先看描述判断相关性，不要一次搜很多词。**
2. 详情：`skillmaster show <命名空间>/<名称>`
   → 返回完整文件清单但**没有内容**。据此判断这个 skill 有没有你要的那部分。
   记下这次拿到的版本号（响应里的 `version.number`，形如 `3`）。
3. 取正文：`skillmaster get <命名空间>/<名称>@<版本号>`
4. 取文件：正文里引用到的文件才取 `skillmaster get <命名空间>/<名称>@<版本号> <relpath>`

## 版本要一路带着（第 3、4 步必须写 `@版本号`）

第 2 步得到的是**某一个版本**的清单。后续每条命令都带上那个版本号，取的才是**清单里
开列的那些**文件。

**不写版本号就是从入口再进一次**，等于重新解析「最新版」：如果这中间有人发布了新版本，
你手上的清单和取回的内容就对不上，**而且不会有任何报错**。所以：

- 不要在第 3、4 步重写 `<命名空间>/<名称>`——把它替换成第 2 步的 `<命名空间>/<名称>@<版本号>`。
- 一次任务里只进一次入口（第 2 步），之后一直用那个版本号。

## 停止条件

- 搜索结果没有相关项 → 直接告诉用户没找到，**不要**逐个试。
- 清单里有文件但正文没引用 → **不要取**。
