# Archived Python baseline

This is the pre-rewrite server, kept as an **executable design reference** for the Java
implementation that now lives in the parent directory. It is not built, not tested, and not
part of any image or workflow.

Its defects are catalogued in
[`docs/versions/v1-hosting/known-issues.md`](../../docs/versions/v1-hosting/known-issues.md),
and each module's disposition is decided in
[`technical-design.md`](../../docs/versions/v1-hosting/technical-design.md) §6. When the Java
code covers the same ground, this directory goes away — see
[ADR 0011](../../docs/decisions/0011-server-and-cli-stack.md).
